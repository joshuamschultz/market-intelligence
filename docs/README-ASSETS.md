## Capture and generation notes

- Hero art and explanatory diagrams are conceptual images; they are not evidence of feature completion, measured speed, market performance, or complete data coverage. The full prompts and generator metadata are in `docs/assets/image-prompts.json`.
- The data-pipeline graphic says “Private warehouse · Explicit opt-in for AI journal context.” The warehouse and credentials are stored locally. When a user requests optional Claude generation, selected market context is sent to Anthropic; notes are included only with a separate opt-in.
- The three product images were captured from native Chrome using CUA → DevTools → “Capture screenshot” with the tool viewport undocked. Each image is 3024×1592 and excludes browser chrome. The tool dock and window state were restored afterward. The app UI and data were not edited for capture.
- Avoid credentials, private notes, API tokens, local filesystem paths, and unrelated personal data in every screenshot. Verify the final files at the listed relative paths before linking them from README.
- Keep captions and surrounding text accurate if a view is empty, partial, waiting for preparation, or based on an observed universe. An alt description states what the image shows; it should not claim hidden controls or unshown calculations.
- When an asset is added or replaced, record its actual source/provider, capture date and active app build (for screenshots), dimensions, and any crop. Keep conceptual diagrams distinguishable from native product screenshots.
